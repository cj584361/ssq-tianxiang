# 天象选号 · 双色球

按当天干支、节气、建除、五行生成双色球号码的**娱乐工具**。
网页版，自带一个零依赖小服务，开奖后自动同步官方数据；号码与设置全存本地。

---

## 为什么是网页，不是小程序

原计划是做成微信小程序，查证后确认**个人主体做不了**。微信开放社区的官方说明原文：

> 当小程序涉及彩票服务，属**个人主体小程序未开放类目**，建议申请企业主体小程序。
> 请下架尚未开放服务类目内容或申请企业主体小程序合规提审，
> 否则代码审核环节将面临**因类目不符被驳回**情形。

社区里有人问「只提供纯机选工具、不做查询和预测行不行」，同样被驳回。
也就是说，**哪怕去掉一切"预测"表述，只要是双色球选号，个人主体都过不了**。

另外还有两条隐性障碍，即使换成企业主体也绕不开：

1. **玄学内容**：平台运营规范禁止宣扬封建迷信，"宜忌定号"容易被判定违规
2. **地图接口**：内嵌地图要申请地理位置接口，个人主体基本不批；
   而请求外部开奖数据必须配置已备案的合法域名，此项目没有自有域名

所以改成**单文件网页**：功能一个不少，且没有审核、没有备案、没有服务器。
在手机上用浏览器打开，再「添加到主屏幕」，体验与小程序差别很小。

## 怎么用

**电脑**：双击 `start.bat`，浏览器会自动打开 `http://127.0.0.1:5173`。

**手机**：
1. 把整个文件夹传到手机（微信文件传输助手 / 网盘都行）
2. 用浏览器打开 `index.html`
3. 浏览器菜单 →「添加到主屏幕」，之后像 App 一样点开

> **为什么建议用 `start.bat` 而不是直接双击 `index.html`**

| 打开方式 | 号码/天象 | 开奖自动同步 | 内嵌地图 |
|---|---|---|---|
| `start.bat`（本地服务） | ✓ | ✓ | ✓ |
| 直接双击 `index.html` | ✓ | ✗ 浏览器禁止 file:// 联网 | ✗ 需要安全上下文 |
| 手机浏览器打开 | ✓ | ✗ 同理 | ✗ |

直接双击时页面会明确提示"离线打开"，此时**手动填写开奖号**照样能比对，
其余功能一个不少。想两者都要，就走 `start.bat`，或把文件夹放到任意 https 静态托管上。

`start.bat` 做的事只有一件：用 Node 起一个本地服务（默认 `127.0.0.1:5173`），
既托管页面，也把福彩官网的数据转给页面。**只监听本机，不对外，不需要备案。**

## 四个模块

**1. 今日天象**
- 公历日期、星期、距下一个节气天数
- 年 / 月 / 日三柱干支（年柱以**立春**为界，不是元旦）
- 十二建星（建除满平定执破危成收开闭），附释义与黄道/黑道判定
- 日主五行、冲煞方位、月相（含被照亮百分比）

**2. 今日号码**
- 每天只给**一组**：6 红 + 1 蓝，不铺垫、不列一堆备选
- 显示「取号依据」，把参与运算的天象要素全部列出
- 可用日期左右箭头切到任意一天，看那天会出什么号
- 「换一组」在同一天里换编号，刷新后仍保留你选的那组

**确认 → 自动判奖**

点「确认这组」后，页面会先算出这组号等的是哪一期（最近的未来开奖日），然后：

| 情况 | 表现 |
|---|---|
| 还没开奖 | 徽标「未开奖」，写明几月几日周几 21:15 开奖，并承诺开奖后自动比对 |
| 已过开奖时间但没拿到数据 | 提示「应该已经开奖了」，引导点「立即同步」 |
| 开奖了，中了 | 徽标「中奖」，直接给出奖级与固定奖金 |
| 开奖了，没中 | 徽标「未中奖」，附红球命中数、蓝球是否命中 |

判断依据是开奖公告的**开奖日期**与这组号的目标期匹配，不是靠期号推算，
所以跨年、跨批次都不会错判。结果一旦判出就冻结保存，之后官方数据继续刷新也不会覆盖掉。
确认时会同时在「我的号码」留一条记录，开奖后自动回填期号。

**3. 上期开奖**
- 自动同步中国福彩官网的最新一期，号码以**大号红蓝球**展示（6 红 + 1 蓝）
- 带期号、开奖日期与星期、奖池金额、当期销量
- 开奖后自动刷新：平日 8 分钟一次，周二/四/日 21:15–22:15 加密到 2 分钟一次
- 拿到新一期会自动与今日号码比对，直接判到具体奖级与固定奖金
- 暂无数据时球位显示虚线空球；取不到数据时退回折叠的手动填写区
**4. 周边彩票店**
- 填高德 Key → 内嵌地图 + 3 公里内店铺列表
- 不填 → 一键跳转高德搜索

## 选号算法

```
种子 = 日期 | 年干支 | 月干支 | 日干支 | 建除 | 五行 | 节气
随机数 = mulberry32(FNV-1a(种子 + "#" + 序号))
红球 = 1–33 洗牌取前 6 个并升序
蓝球 = 1–16 独立抽取
```

**这个设计是确定性的**：同一天、同一序号，必然得到同一组号码。
这样做不是为了"更准"，而是为了让号码**有出处**——你昨天看到的和今天看到的一致，
而不是每次刷新都变，那会显得像随便糊弄。

**它不能提高中奖概率。** 双色球每期是独立随机事件，任何算法都做不到。

## 历法实现说明

没有用农历数据表，全部走天文公式现算，所以能覆盖任意年份且不依赖外部数据。

| 项目 | 方法 | 精度 |
|---|---|---|
| 日干支 | 儒略日 `(JDN + 49) % 60` | 精确 |
| 年干支 | 以立春（黄经 315°）为界 | 精确 |
| 月干支 | 五虎遁 + 节气月 | 精确 |
| 节气 | 太阳视黄经，迭代求 15° 整倍数 | 误差约 15 分钟 |
| 建除十二神 | `(日支 − 月建 + 12) % 12` | 精确 |
| 月相 | 日月黄经差（简化 ELP） | 误差数小时 |

**已与三个黄历站点交叉对账**（2026-10-24 至 10-28 连续五天）：

| 日期 | 本程序 | 站点 |
|---|---|---|
| 10-24 | 辛未日 · 收日 | 辛未日 · 收日 ✓ |
| 10-25 | 壬申日 · 开日 | 壬申日 · 开日 ✓ |
| 10-26 | 癸酉日 · 闭日 | 癸酉日 · 闭日 ✓ |
| 10-27 | 甲戌日 · 建日 | 甲戌日 · 建日 ✓ |
| 10-28 | 乙亥日 · 除日 · 霜降 · 冲蛇煞西 | 同左 ✓ |

**没做二十八宿**：查证时发现不同黄历站给同一天的星宿不一致
（2026-10-28 有的说"壁水貐"、有的说"井木犴"），数据源本身有分歧，
做上去反而会给出错误信息，所以略去。

## 开奖数据同步

**数据源**：中国福彩官网开奖公告接口
`https://www.cwl.gov.cn/cwl_admin/front/cwlkj/search/kjxx/findDrawNotice?name=ssq`

官方数据，与公告页一致，不是抓第三方聚合站。

**为什么需要 `server.js`**

这个接口不返回 `Access-Control-Allow-Origin` 头，浏览器里直接 `fetch` 会被跨域策略拦掉；
`file://` 打开时更彻底，连请求都发不出去。所以由本地服务同源转发：

```
浏览器 ──GET /api/latest──▶ server.js ──▶ 福彩官网
        ◀── 精简 JSON ────
```

**刷新策略**

| 场景 | 行为 |
|---|---|
| 打开页面 | 先渲染本地缓存，同时拉一次最新 |
| 平时 | 每 8 分钟一次 |
| 开奖日 21:15–22:15 | 每 2 分钟一次（双色球周二、四、日 21:15 开奖） |
| 切回标签页 | 距上次同步超过 8 分钟就补一次 |
| 后台标签页 | 暂停轮询，不浪费流量 |

**缓存**：服务端缓存 8 分钟，一期结果不会变，避免反复打官网。
官网临时故障时会返回上次结果并标注"缓存"，不会白屏。

**失败降级**：拿不到就提示原因，并保留手动填写入口；天象、选号、比对逻辑全在本地，离线可用。

**隐私**：只请求开奖公告，不上传任何本地数据。期号与号码存在 `localStorage`。

## 地图配置

1. 到 [高德开放平台](https://lbs.amap.com/) 注册，创建应用
2. 添加 Key，服务平台选 **Web 端（JS API）**
3. 把 Key 粘到页面「周边彩票店 → 配置密钥」

Key 只存在浏览器 localStorage，不上传任何地方。
免费额度对个人使用足够。

## 数据存储

全部在 `localStorage`，键名 `sky.ssq.*`。换浏览器或清缓存会丢，不会同步到任何服务器。

```
双色球天象选号/
├── start.bat     双击启动：拉起本地服务并打开浏览器
├── server.js     零依赖 Node 服务：静态托管 + 开奖数据转发（约 200 行）
```

接口：

| 路径 | 说明 |
|---|---|
| `GET /` | 页面 |
| `GET /api/latest` | 最新一期开奖（精简 JSON，含期号/红球/蓝球/日期/销量/奖池） |
| `GET /api/health` | 服务状态与缓存时间 |
