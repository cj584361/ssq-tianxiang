# 腾讯云云函数（SCF）版同步

跑在腾讯云国内机房上抓福彩官网，写回 GitHub 的 `data.json` / `history.json`。
**电脑不用开机**，GitHub Pages 约 1 分钟后自动更新。

- 脚本：`index.js`（零依赖，只用 Node 内置 `https`，不用打包 zip）
- 测试：`node scf-sync/test.js` → 45 条断言全绿
- 费用：每月免费额度（100 万次调用 / 40 万 GB·秒）远超需求，实测配置下 **0 元**

## 和金山文档 AirScript 版的区别

| | 腾讯云 SCF | 金山文档 AirScript |
|---|---|---|
| 要实名开云账号 | 要（微信扫码，几分钟） | 不用 |
| 能不能同时更新奖金曲线那 100 期 | ✅ 能 | 只有最新一期 |
| 限制 | 需配环境变量和触发器 | 不支持 async / `?.` 等语法 |
| 稳定性 | 强（专业定时器） | 一般（文档平台附带功能） |

两条路都能走通，选一个就行。SCF 更完整，AirScript 更省事。

## 一、创建函数（约 5 分钟）

1. 打开 <https://console.cloud.tencent.com/scf>，微信扫码登录，按提示完成**实名认证**（个人，扫码即可）
2. 顶部地域选 **广州**（或上海、北京）
   > ⚠️ 千万别选「中国香港 / 新加坡 / 硅谷」，海外节点抓不到福彩官网，跟 GitHub 一样会被拒
3. 点 **新建** → 选 **从头开始**
4. 按下表填：

| 配置项 | 填什么 | 为什么 |
|---|---|---|
| 函数类型 | 事件函数 | Web 函数是给 HTTP 服务用的 |
| 函数名称 | `ssq-sync` | 随意 |
| 地域 | 广州 | 必须国内 |
| 运行环境 | Node.js 18.15（有 20 也行，16 也行） | 脚本兼容全部版本 |
| 提交方法 | **在线编辑** | 不用打 zip 包 |
| 执行方法 | `index.main_handler` | 脚本里的入口名 |
| 时区 | `Asia/Shanghai（北京时间）` | 跟开奖时刻对齐 |
| 函数代码 | 先随便，下一步覆盖 | — |

5. 点 **完成**

## 二、粘贴代码

进入函数详情 → **函数代码** 页签 → 左边文件树点 `index.js` → 把内容**全选删掉**，粘贴本目录 `index.js` 的全文 → 点 **部署**（等右上角提示"部署成功"）。

> 代码约 400 行。别只粘一半，最后必须有 `exports.main_handler = async function ...`。

## 三、把超时改大（这一步漏了必失败）

**函数配置** 页签 → 找到 **执行超时时间** → 从默认的 **3 秒** 改成 **60 秒** → 保存。

默认 3 秒根本不够：光抓官网 + 抓 100 期就要 2~5 秒，更别说还要跟 GitHub 来回四次。

## 四、先自检（这一步决定方案成不成立）

不要急着配 token。先确认**腾讯云能不能访问福彩官网**——这是整个方案唯一的风险点。

**函数代码** 页签右上方 → **测试** → 弹出框里写 `{}` → 确定。

去 **日志查询** 页签，找这几行：

```
[双色球同步] 模式：自检（只抓不写）
[双色球同步] 官网状态码：200
[双色球同步] 官网最新：第 2026124 期 2026-10-29（周四）红 3 11 17 22 23 29 蓝 9
[双色球同步] 官网历史：100 期，最新 2026124
[双色球同步] 自检模式（DRY_RUN=1），没有推送。
```

| 看到什么 | 说明 |
|---|---|
| 上面这样，有期号和红蓝球 | ✅ 通了，继续第五步 |
| `官网返回 HTTP 403` / `412` / 超时 | ❌ 机房 IP 也被官网挡了，换个地域再试（上海、北京）；三个地域都不行就只能回退本机 `sync-push.bat` |
| `官网没返回开奖记录` | 官网改版或被 WAF 拦，把日志发我 |
| `请求超时` | 多半是没网或超时没改大 |

## 五、生成 GitHub token

1. 打开 <https://github.com/settings/personal-access-tokens/new>
2. **Token name**：`ssq-sync`
3. **Expiration**：1 年（到期要换，日历里记一下）
4. **Repository access** → 选 `Only select repositories` → 勾 `ssq-tianxiang`
5. **Permissions** → 展开 `Repository permissions` → 找到 **Contents** → 选 `Read and write`
   > 只勾这一个。别的都不用，最小权限最安全。
6. 点 **Generate token**，复制 `github_pat_...` 那一串（**只显示一次**）

## 六、配环境变量

**函数配置** → **环境变量** → 编辑 → 加两条：

| 键 | 值 |
|---|---|
| `GH_TOKEN` | 刚才复制的 `github_pat_...` |
| `DRY_RUN` | `0` |

保存。`DRY_RUN` 不写默认就是 `1`（自检），写 `0` 才真的往 GitHub 推。

> 想临时停机：把 `DRY_RUN` 改回 `1` 即可，代码不用动。

## 七、再测一次

**测试** → `{}` → 看日志：

```
[双色球同步] 模式：自动（抓取 + 推送 GitHub）
[双色球同步] 已写入 data.json：2026123 → 2026124
[双色球同步] 已写入 history.json：100 期，最新 2026124
[双色球同步] 已提交：data.json、history.json。约 1 分钟后线上生效
```

然后打开 <https://cj584361.github.io/ssq-tianxiang/>，右上角应该是「已同步（绿）」。
GitHub 仓库的 commit 记录里会多两条 `chore: 腾讯云函数同步第 2026124 期开奖`。

如果显示「已经是第 2026124 期，跳过」——说明数据本来就是最新的，正常，说明读仓库也通了。

## 八、加定时触发器

**触发管理** → **创建触发器**：

| 配置项 | 填什么 |
|---|---|
| 触发方式 | 定时触发 |
| 定时任务名称 | `ssq-draw-night` |
| 触发周期 | 自定义 |
| Cron 表达式 | `0 25,45 21 * * * *` |

含义：每天 **21:25** 和 **21:45** 各跑一次。

> 双色球 21:15 开奖，结果通常 21:20 前后上网。21:25 抓第一次，21:45 兜底。
> 只在周二/四/日有新数据，其余日子跑一次发现「期号没变」就直接退出，不产生提交。
> 想更稳可以再加一条触发器 `0 40 22 * * * *`（22:40 兜底一次）。

**关于时区**：腾讯云 SCF 的 Cron 是 **7 位**（秒 分 时 日 月 周 年），并且控制台上会明写「Cron 当前以 UTC+8 中国标准时间运行」。但创建触发器页面还有一处**时区**下拉，**确认为 `Asia/Shanghai`**，别选 UTC——选了 UTC 就会晚 8 小时，凌晨 5 点才跑。

## 九、验证定时器

创建完触发器后，等一个 21:30 看 **日志查询** 有没有新记录；不想等就点触发器列表的「立即运行」测一次。

## 出问题怎么查

| 日志/现象 | 原因 | 怎么办 |
|---|---|---|
| `GH_TOKEN 没配` | 环境变量没加或没保存 | 加 `GH_TOKEN`，保存后**重新测试** |
| `GitHub 返回 401` | token 过期/复制不全 | 重新生成 |
| `GitHub 返回 403` | 没给 Contents 写权限 | 编辑 token 权限，或重新生成 |
| `写 data.json 失败：HTTP 409` | 正好跟别的进程撞了 | 等下次触发，会自动重试成功 |
| `Task timed out` | 超时还是 3 秒 | 回去做第三步 |
| `Cannot find module 'https'` | 运行环境选错 | 重选 Node.js |
| `exports is not defined` | 粘成了 `main_handler` 以外的文件 | 确认粘在 `index.js` 里 |
| 一直不触发 | 触发器时区选了 UTC | 改 `Asia/Shanghai`，或 cron 小时减 8 |

## 想改行为

全靠环境变量，不用改代码：

| 键 | 默认 | 说明 |
|---|---|---|
| `GH_TOKEN` | 空 | 必填（`DRY_RUN=0` 时） |
| `DRY_RUN` | `1` | `1` 只抓不写，`0` 真推送 |
| `SYNC_HISTORY` | `1` | `0` 表示不更新奖金曲线的 100 期 |
| `GH_OWNER` / `GH_REPO` / `GH_BRANCH` | `cj584361` / `ssq-tianxiang` / `main` | 换仓库时才改 |

## 它和别的几条链路的关系

| 打开方式 | 数据源 | 谁在更新 |
|---|---|---|
| `start.bat` | `/api/latest` 直连官网 | 本机 server.js，实时 |
| GitHub Pages | `data.json` / `history.json` | **本云函数**（或 AirScript / `sync-push.bat`） |
| 双击 `index.html` | 无 | 手动填 |

三条互不冲突。云函数只负责让 Pages 版跟上，不影响本机版。
