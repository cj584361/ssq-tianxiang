# 金山文档 AirScript 版同步（电脑不用开机）

用金山文档的「智能表格 + AirScript + 定时任务」代替云函数：

```
金山云（国内 IP）──抓──▶ 福彩官网 ──▶ 写回 GitHub 的 data.json ──▶ Pages 1 分钟生效
```

免费、不用实名开云账号、不用电脑常开。**但前提是金山云的出口能访问福彩官网**——
这一点我没法替你验证，脚本第一次运行（自检模式）就会给出答案。

---

## 先说清楚：不是普通 Excel

| 有什么 | 没有什么 |
|---|---|
| 金山文档「**智能表格**」（又叫多维表格 / 协作表格） | 普通 `.xlsx` 上传到金山文档 → **没有 AirScript** |
| 智能表格菜单「效率 → 高级开发 → AirScript 脚本编辑器」 | WPS Office 本地客户端的普通表格 → 只有基础宏，没有定时任务 |
| 「效率 → 高级开发 → 定时任务」 | |

所以第一步一定是**在金山文档网页版新建一张智能表格**，不是打开你现有的 Excel 文件。

---

## 配置步骤

### 1. 新建智能表格

金山文档 → 新建 → **智能表格**。随便起个名，比如「开奖同步」。表格本身不用填任何东西，脚本只用它的运行环境。

### 2. 打开脚本编辑器，粘贴脚本

智能表格菜单 → **效率 → 高级开发 → AirScript 脚本编辑器** → 新建脚本。

把 [`airsync.js`](./airsync.js) 全文粘进去。

### 3. 添加「网络 API」服务（漏了必报错）

编辑器**工具栏 → 服务** → 勾上 **网络 API**。

不加这一步，脚本第一行请求就会抛 `HTTP is not defined`。

### 4. 先跑一次自检

脚本默认：

```js
TEST_ONLY: true,   // 只抓官网、打日志，不碰 GitHub
TOKEN: '',
```

直接点「运行」，看底部日志面板。三种结果：

| 日志 | 含义 | 下一步 |
|---|---|---|
| `官网 HTTP 状态：200` + `官网最新：第 2026124 期 …` | ✅ 金山云能访问官网 | 继续第 5 步 |
| `HTTP 状态：403` / `412` / 超时 / `result 为空` | ❌ 金山云也被拦了 | 这条路走不通，回到 `sync-push.bat` 或国内云函数 |
| `HTTP is not defined` | 忘了第 3 步 | 加「网络 API」服务 |

**这一步是整条路的判定点**，跑通再往下配。

### 5. 生成 GitHub token

GitHub → Settings → Developer settings → **Personal access tokens → Fine-grained tokens** → Generate new token。

- **Repository access**：Only select repositories → 只勾 `ssq-tianxiang`
- **Permissions** → Repository permissions → **Contents: Read and write**（其余全部留 No access）
- **Expiration**：最长 1 年，到期要换（细粒度 token 不支持永不过期）

生成后复制 `github_pat_...`，只显示一次。

### 6. 填配置，再跑一次

改脚本顶部两行：

```js
TEST_ONLY: false,
TOKEN: 'github_pat_你的token',
```

再点「运行」。成功的日志长这样：

```
官网最新：第 2026124 期 2026-10-29（周四）红 03 11 17 22 23 29 蓝 09
仓库里是 2026123，准备写入第 2026124 期
已推送。约 1 分钟后线上生效
```

去 https://cj584361.github.io/ssq-tianxiang/ 刷新确认。再跑一次应该提示「无需更新」——说明去重生效。

### 7. 建定时任务

**效率 → 高级开发 → 定时任务 → 新建任务**：

- 选择脚本：必须选**「文档共享脚本」**里那个（不是临时脚本，否则列表里找不到）
- 触发方式：每天
- 时间：**21:45**

开奖 21:15、官网通常 21:30 前后出数，21:45 比较稳。想更保险就再建一个 **22:15** 的——脚本有期号去重，重复跑不会产生多余提交。

周二、周四、周日开奖，其余日子跑也是「无需更新」，没有副作用。

## 注意事项

**token 是明文存在脚本里的。** 这张智能表格别共享给别人、别公开发布，否则等于把仓库写权限送人。真要共享，先把文件里的 `TOKEN` 删掉。

**每天两次调用，免费额度够用。** AirScript 的定时任务和网络 API 都是免费功能（WPS 官方文档：进阶开发相关操作不要求会员）。

**脚本的语法限制**（改代码时注意，AirScript 不是完整环境）：
不支持 `async/await`、`?.` 可选链、对象里简写方法 `{ foo() {} }`、`class`，也没有 `Buffer`/`btoa`/`TextEncoder`。HTTP 请求本身是同步的，不需要 async。

**改完脚本先跑本地测试**：

```bash
node wps-sync/test.js
```

46 条断言覆盖 base64 编解码、字段归一化、GitHub 读写流程（含 sha 乐观锁、同期去重）、禁用语法扫描。全绿再往金山文档里贴。

## 和 `sync-push.bat` 的关系

两者做同一件事，**选一个就行**：

| | AirScript 版 | `sync-push.bat` |
|---|---|---|
| 电脑要开机 | ❌ 不用 | ✅ 要 |
| 需要配 token | ✅ 需要 | ❌ 不用（走本机 SSH key） |
| 更新 `history.json`（奖金曲线） | ❌ 只更新 `data.json` | ✅ 两个都更新 |
| 依赖第三方平台 | ✅ 金山云 | ❌ 无 |

奖金曲线那张图用的是 `history.json`（近 100 期），AirScript 版没有维护它。曲线数据不会错，只是新一期不会自动补进去——偶尔双击一次 `sync-push.bat` 就补齐了。
